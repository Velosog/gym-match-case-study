# Security Policy

This repository contains documentation only: a case study of a project whose
source code is private. It runs no code and holds no data.

## Reporting a problem

Please **do not** open a public issue or pull request for a security or
privacy concern, such as content here that looks like a credential, an
internal URL or someone's personal data.

Report it privately to the repository owner through their GitHub profile:
<https://github.com/Velosog>

Include the file and the line, and why you think it is sensitive.

## What to expect

This is a solo-maintained repository. Reports are acknowledged on a
best-effort basis, and confirmed problems are removed from the content and,
when needed, from the git history.
